# Leominal v1.1.1

Leominal v1.1.1 tightens the full-screen app behavior so the browser page itself stays fixed while terminal history remains scrollable.

## Highlights

- Locked the document, body, and root containers so Leominal does not become a page-level scroll surface on desktop or mobile browsers.
- Added mobile touch handling that prevents browser page panning while preserving expected terminal scrollback movement inside xterm.
- Contained internal scroll regions such as workspace lists, tab lists, the mobile key bar, and upload results so they do not drag the app shell.

## Verification

- `npm run typecheck`
- `npm test`
- `npm run build`
- local LaunchAgent redeploy with `/api/auth/session` health check

## Notes

- The app remains a full-screen terminal surface; scroll gestures over the terminal are mapped to xterm scrollback instead of moving the page.
