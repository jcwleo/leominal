# Leominal v1.3.0

Leominal v1.3.0 adds opt-in authenticator-app 2FA from a general Settings modal and includes terminal WebSocket output batching from the local main branch.

## Highlights

- Added a Settings button next to logout in the workspace sidebar footer.
- Added a general Settings modal with a Security section that can host future settings.
- Added opt-in TOTP enrollment with QR code and manual setup key support.
- Added password plus authenticator-code login after 2FA is enabled.
- Added short-lived pending 2FA cookies that are not accepted as full terminal sessions.
- Invalidates earlier password-only sessions after 2FA enrollment, while preserving the confirming session.
- Hardened TOTP login rate limiting against challenge cycling.
- Drops malformed persisted TOTP secrets during local state normalization.
- Batched terminal WebSocket output to reduce hot-path write pressure.

## Verification

- `npm run build`

- `git diff --check`
- local production deploy with `/api/auth/session` health check

## Notes

- This release keeps `package.json` private and publishes source through GitHub only; no npm package is published.
- 2FA is a local access hardening layer. The TOTP seed is stored in the local state file; losing the authenticator requires resetting the local state file.
- There is no disable-2FA or recovery-code UI in this release.
