# Leominal v1.2.0

Leominal v1.2.0 adds an active-pane file explorer with embedded text editing and Markdown preview support.

## Highlights

- Added a Files sidebar tab that follows the active terminal pane's working directory.
- Added a tree-style file explorer scoped to the active pane cwd.
- Added click-to-preview behavior for text, Markdown, image, and PDF files.
- Added explicit file opening by double-click or Enter, creating a dedicated embedded editor pane.
- Added autosave for edited text documents.
- Added Markdown preview mode inside editor panes.
- Added cwd refresh requests from the active terminal pane after Enter, with follow-up checks for delayed directory changes.
- Added stale-root recovery so file actions refresh the explorer instead of showing a cwd mismatch error.

## Verification

## Notes

- This release keeps `package.json` private and publishes source through GitHub only; no npm package is published.
- Files explorer roots remain scoped to the active terminal pane cwd and are refreshed when the active pane or observed cwd changes.
