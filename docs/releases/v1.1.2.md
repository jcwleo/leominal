# Leominal v1.1.2

Leominal v1.1.2 fixes tmux-specific terminal rendering and mobile scroll behavior.

## Highlights

- Fixed tmux sessions inheriting an unsuitable terminal environment by forcing browser PTYs to advertise `TERM=xterm-256color`, `COLORTERM=truecolor`, and a UTF-8 character locale.
- Preserved existing UTF-8 locales when the host environment already provides one.
- Fixed one-finger terminal drags inside tmux by forwarding touch scroll gestures through xterm's wheel handling when tmux or another alternate-screen app owns scrolling.
- Kept normal shell scrollback behavior unchanged for non-tmux terminal output.
- Included the app reload control changes that were pending after v1.1.1.
