# Leominal v1.1.3

Leominal v1.1.3 improves terminal keyboard handling across pane focus, clipboard behavior, and app-level workspace shortcuts.

## Highlights

- Hardened terminal pane focus and report handling so inactive panes do not answer terminal report queries.
- Improved terminal copy behavior by preserving terminal interrupts on plain `Ctrl+C` while supporting selection copy through browser copy shortcuts.
- Stripped trailing line breaks from pasted terminal text so a pasted command does not execute immediately.
- Remapped app shortcuts away from browser-reserved Command combinations.
- Added pane index navigation with `Ctrl+1` through `Ctrl+9`.
- Added workspace index navigation with `Ctrl+Shift+1` through `Ctrl+Shift+9`.
- Added pane cycling with `Ctrl+Option+[` and `Ctrl+Option+]`.
- Added split shortcuts with `Ctrl+Option+Shift+Right` and `Ctrl+Option+Shift+Down`.
- Added hover tooltip hints for split and workspace shortcut buttons.
- Documented the shortcut map in the README.
