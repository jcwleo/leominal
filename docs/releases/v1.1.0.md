# Leominal v1.1.0

Leominal v1.1.0 focuses on making the web terminal more practical as a full-screen mobile terminal while keeping the desktop workflow intact.

## Highlights

- Added drag-and-drop file upload into the active terminal cwd, with collision-safe destination names.
- Added pane navigation shortcuts for faster keyboard-driven terminal movement.
- Added browser-safe pane index shortcuts so browser-reserved key combinations do not steal terminal workflow shortcuts.
- Added a mobile terminal input assistant with compact buttons for Control, Esc, Tab, and arrow keys.
- Added Control modifier arming for mobile, so hardware-like terminal control input can be composed with the OS keyboard.
- Added mobile keyboard-aware positioning so the terminal key bar stays visible above the software keyboard.
- Locked mobile browser zoom for a full-screen terminal feel, including viewport scale limits, iOS focus-zoom prevention, and gesture zoom guards.

## Verification

- `npm test`
- `npm run typecheck`
- `npm run build`
- focused Playwright checks for the mobile terminal key bar and terminal close flow

## Notes

- The mobile key bar is only shown on narrow mobile layouts.
- iOS still owns the system keyboard area; Leominal positions controls at the bottom of the visible browser viewport above the keyboard.
